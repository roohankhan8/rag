# Python Basics

## Lists

A Python list is an ordered, mutable collection. Lists can contain values of different types and are commonly created with square brackets, such as `[1, 2, 3]`.

## Dictionaries

A dictionary stores key-value pairs. A dictionary is useful when values need to be looked up by a meaningful key instead of a numeric position.

## Functions

Functions group reusable behavior. They are defined with the `def` keyword and can receive arguments and return values.

## Virtual environments

A virtual environment keeps project dependencies separate from the system Python installation. Create one with `python -m venv .venv` and activate it before installing packages.
